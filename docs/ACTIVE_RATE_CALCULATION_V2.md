# Active率の計算方法（学習期間方式）

## 概要

各企業の利用開始から3ヶ月間のデータを分析し、その期間に使用された機能を「利用する機能」として記録します。
それ以降は、その機能リストを基準にActive率を計算します。

```
Active率 = (現在期間で使用した機能数 / 利用する機能数) × 100
```

## 実装方法

### 1. 利用開始日の記録

各企業の利用開始日を記録します。

**データベース構造：**
- `ユーザー基礎情報`テーブルに`usage_start_date`カラム（DATE型）を追加
- または、最初の利用ログの日付を自動的に使用

### 2. 学習期間の定義

- **学習期間**: 利用開始日から3ヶ月間
- **学習期間中のデータ**: この期間の利用ログを分析
- **利用する機能**: 学習期間中に1回以上使用された機能

### 3. 利用する機能の記録

学習期間終了後、以下の情報を記録します。

**データベース構造：**
- `ユーザー基礎情報`テーブルに`used_features`カラム（JSONB型）を追加

**データ形式（JSON）：**
```json
{
  "features": [
    "ログイン",
    "見積作成",
    "工事登録",
    "顧客登録"
  ],
  "learning_period_end": "2024-04-01",
  "last_updated": "2024-04-01T00:00:00Z"
}
```

### 4. Active率の計算

学習期間終了後、以下のロジックでActive率を計算します。

1. 現在期間の利用ログから、各機能の利用状況を確認
2. 「利用する機能」リストに含まれる機能のうち、実際に使用した機能をカウント
3. Active率 = (使用した機能数 / 利用する機能数) × 100

**例：**
- 利用する機能: 10個（ログイン、見積作成、工事登録、顧客登録、業者登録、請求書作成、商品発注書作成、外注発注書作成、現場連絡表作成、実行予算作成）
- 現在期間で使用した機能: 3個（ログイン、見積作成、工事登録）
- Active率 = (3 / 10) × 100 = 30%

## 処理フロー

### ステップ1: 利用開始日の設定

1. 企業の最初の利用ログを検索
2. その日付を利用開始日として記録

### ステップ2: 学習期間の判定

1. 現在日付が利用開始日から3ヶ月以内かどうかを判定
2. 学習期間中の場合、利用する機能の更新をスキップ
3. 学習期間終了後、利用する機能を更新

### ステップ3: 利用する機能の更新

1. 利用開始日から3ヶ月間の利用ログを取得
2. 各機能の利用状況を集計
3. 1回以上使用された機能を「利用する機能」として記録

### ステップ4: Active率の計算

1. 現在期間の利用ログを取得
2. 「利用する機能」リストに基づいてActive率を計算
3. 計算結果を利用ログに保存

## メリット

1. **各企業の実際の利用パターンに基づく**: 初期の利用状況を学習期間として活用
2. **より正確なActive率**: 企業ごとに異なる利用パターンを反映
3. **自動更新**: 学習期間終了後、自動的に利用する機能を更新
4. **柔軟性**: 新しい機能が追加されても、学習期間中に使用されれば自動的に含まれる

## 注意点

1. **学習期間中のActive率**: 学習期間中は、全機能を基準に計算（または計算しない）
2. **利用開始日の設定**: 既存企業の場合は、最初の利用ログの日付を使用
3. **機能の追加**: 学習期間終了後に新しい機能が追加された場合、次回の学習期間更新まで反映されない
