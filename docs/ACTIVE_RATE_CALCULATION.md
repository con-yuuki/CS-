# Active率の計算方法

## 概要

Active率は、各企業が利用可能な機能のうち、実際に使用した機能の割合を表します。

```
Active率 = (使用した機能数 / 利用可能な機能数) × 100
```

## データ構造

### 1. 企業マスタに機能リストを追加

各企業が利用可能な機能のリストを管理します。

**データベース構造：**
- `ユーザー基礎情報`テーブルに`available_features`カラム（JSONB型）を追加

**データ形式（JSON）：**
```json
{
  "features": [
    "ログイン",
    "見積作成",
    "工事登録",
    "顧客登録",
    "業者登録",
    "請求書作成",
    "商品発注書作成",
    "外注発注書作成",
    "現場連絡表作成",
    "実行予算作成",
    "書類メール送信",
    "資料登録",
    "写真登録",
    "工程表作成",
    "タスク登録",
    "日報登録"
  ]
}
```

### 2. 利用ログに使用機能を記録

各期間で実際に使用した機能を記録します。

**データ形式（JSON）：**
```json
{
  "used_features": [
    "ログイン",
    "見積作成",
    "工事登録"
  ]
}
```

または、各機能の利用状況を個別に記録：

```json
{
  "feature_usage": {
    "ログイン": true,
    "見積作成": true,
    "工事登録": false,
    "顧客登録": false,
    "業者登録": false,
    "請求書作成": false,
    "商品発注書作成": false,
    "外注発注書作成": false,
    "現場連絡表作成": false,
    "実行予算作成": false,
    "書類メール送信": false,
    "資料登録": false,
    "写真登録": false,
    "工程表作成": false,
    "タスク登録": false,
    "日報登録": false
  }
}
```

## データの渡し方

### 方法1: Excel/CSVファイルから取得

**Excel/CSVファイルの形式：**

| テナントID | 企業名 | ログイン回数 | 見積作成数 | 工事登録数 | 利用可能機能 | 使用機能 |
|-----------|--------|------------|----------|----------|------------|---------|
| 658 | アイランド建工 | 36 | 12 | 11 | ログイン,見積作成,工事登録,顧客登録,業者登録 | ログイン,見積作成,工事登録 |

**「利用可能機能」列：**
- カンマ区切りで機能名を列挙
- 例: `ログイン,見積作成,工事登録,顧客登録,業者登録`

**「使用機能」列：**
- カンマ区切りで実際に使用した機能名を列挙
- 例: `ログイン,見積作成,工事登録`

### 方法2: 各機能の利用状況から自動判定

各機能の利用回数から、使用したかどうかを自動判定します。

**判定ロジック：**
- ログイン回数 > 0 → 「ログイン」機能を使用
- 見積作成数 > 0 → 「見積作成」機能を使用
- 工事登録数 > 0 → 「工事登録」機能を使用
- 顧客登録数 > 0 → 「顧客登録」機能を使用
- 業者登録数 > 0 → 「業者登録」機能を使用
- 請求書作成数 > 0 → 「請求書作成」機能を使用
- 商品発注書作成数 > 0 → 「商品発注書作成」機能を使用
- 外注発注書作成数 > 0 → 「外注発注書作成」機能を使用
- 現場連絡表作成数 > 0 → 「現場連絡表作成」機能を使用
- 実行予算作成数 > 0 → 「実行予算作成」機能を使用
- 書類メール送信数 > 0 → 「書類メール送信」機能を使用
- 資料登録数 > 0 → 「資料登録」機能を使用
- 写真登録数 > 0 → 「写真登録」機能を使用
- 工程表作成数 > 0 → 「工程表作成」機能を使用
- タスク登録数 > 0 → 「タスク登録」機能を使用
- 日報登録数 > 0 → 「日報登録」機能を使用

## 推奨実装方法

**方法2（自動判定）を推奨します。理由：**
1. 既存のインポートデータから自動計算可能
2. データ入力の手間が少ない
3. データの整合性が保たれる

**実装手順：**
1. 企業マスタに`available_features`カラムを追加（JSONB型）
2. 各企業の利用可能機能を設定
3. 利用ログから各機能の利用状況を取得
4. Active率を自動計算

## 計算例

**例1：**
- 利用可能機能: 10個
- 使用した機能: 3個（ログイン、見積作成、工事登録）
- Active率 = (3 / 10) × 100 = 30%

**例2：**
- 利用可能機能: 16個
- 使用した機能: 8個
- Active率 = (8 / 16) × 100 = 50%
