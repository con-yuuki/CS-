## 2. 計算方法

### 2.1 学習期間中（利用開始から3ヶ月間）

**計算対象**: 全16機能

**計算ロジック**:
1. 現在期間の各機能の利用回数を取得
2. 全16機能の利用回数の合計を計算
3. 各機能の利用回数を正規化（合計が100%になるように）
4. 各機能のActive率 = (機能の利用回数 / 全機能の利用回数の合計) × 100

**スコア計算で使用する値**:
- 使用した機能の割合 = (使用した機能数 / 全機能数) × 100
- 使用した機能数: 利用回数 > 0 の機能の数

**例**:
- ログイン: 100回
- 見積作成: 50回
- 工事登録: 30回
- その他: 0回
- 合計: 180回

**各機能のActive率**:
- ログイン: (100 / 180) × 100 = 55.555...%
- 見積作成: (50 / 180) × 100 = 27.777...%
- 工事登録: (30 / 180) × 100 = 16.666...%
- その他: (0 / 180) × 100 = 0%
- **合計: 100%**

**スコア計算用のActive率**:
- 使用した機能数: 3個（ログイン、見積作成、工事登録）
- 全機能数: 16個
- Active率 = (3 / 16) × 100 = 18.75%

### 2.2 学習期間終了後

**計算対象**: 学習期間中に使用された機能のみ（「利用する機能」リスト）

**計算ロジック**:
1. 「利用する機能」リストを取得（学習期間中に1回以上使用された機能）
2. 現在期間の各機能の利用回数を取得
3. 「利用する機能」の利用回数の合計を計算
4. 各機能の利用回数を正規化（合計が100%になるように）
5. 各機能のActive率 = (機能の利用回数 / 利用する機能の利用回数の合計) × 100

**スコア計算で使用する値**:
- 使用した機能の割合 = (使用した機能数 / 利用する機能数) × 100
- 使用した機能数: 利用回数 > 0 の機能の数

**例**:
- 利用する機能: 10個（ログイン、見積作成、工事登録、顧客登録、業者登録、請求書作成、商品発注書作成、外注発注書作成、現場連絡表作成、実行予算作成）
- 現在期間の利用回数:
  - ログイン: 100回
  - 見積作成: 50回
  - 工事登録: 30回
  - その他: 0回
- 合計: 180回

**各機能のActive率**:
- ログイン: (100 / 180) × 100 = 55.555...%
- 見積作成: (50 / 180) × 100 = 27.777...%
- 工事登録: (30 / 180) × 100 = 16.666...%
- その他: (0 / 180) × 100 = 0%
- **合計: 100%**

**スコア計算用のActive率**:
- 使用した機能数: 3個（ログイン、見積作成、工事登録）
- 利用する機能数: 10個
- Active率 = (3 / 10) × 100 = 30%

## 4. 計算フロー

### 4.1 インポート時

1. 利用ログを保存
2. 利用開始日を設定（初回の場合）
3. Active率を計算
   - 学習期間中: 全16機能を基準に計算
   - 学習期間終了後: 「利用する機能」リストを基準に計算
4. 計算結果を`usage_logs`テーブルの`Active率`カラムに保存

### 4.2 スコア計算時

1. 利用ログの`Active率`カラムから取得
2. 未計算の場合は、`calculateActiveRateForLog`を呼び出して計算
3. スコア計算に使用

## 5. 重要なポイント

### 5.1 丸め補正なし

- 割り算の結果をそのまま保持（小数点以下も含む）
- 例: 55.555555...% のまま保持

### 5.2 合計100%になる計算

- 各機能の利用回数を正規化して、合計が100%になるように計算
- ただし、スコア計算では「使用した機能の割合」を使用（合計Active率ではない）

### 5.3 学習期間方式

- 利用開始から3ヶ月間のデータを分析
- この期間に1回以上使用された機能を「利用する機能」として記録
- 学習期間終了後は、このリストを基準にActive率を計算

## 6. データベース構造

### 6.1 ユーザー基礎情報テーブル

- `usage_start_date`: 利用開始日
- `used_features`: 利用する機能のリスト（JSONB型）

### 6.2 usage_logsテーブル

- `Active率`: 計算されたActive率（TEXT型）
- `raw_data`: インポートされた生データ（JSONB型）
