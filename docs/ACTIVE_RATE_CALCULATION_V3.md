# Active率の計算方法（合計100%方式）

## 概要

Active率は、各機能の利用回数を正規化して、合計が100%になるように計算します。

```
各機能のActive率 = (機能の利用回数 / 全機能の利用回数の合計) × 100
合計Active率 = 各機能のActive率の合計 = 100%
```

## 使用する期間

**現在期間の利用回数を使用します。**

- 週次データの場合: 対象週の利用回数
- 月次データの場合: 対象月の利用回数

## 計算対象の機能（16個）

以下の16個の機能の利用回数を使用してActive率を計算します：

1. ログイン
2. 見積作成
3. 工事登録
4. 顧客登録
5. 業者登録
6. 請求書作成
7. 商品発注書作成
8. 外注発注書作成
9. 現場連絡表作成
10. 実行予算作成
11. 書類メール送信
12. 資料登録
13. 写真登録
14. 工程表作成
15. タスク登録
16. 日報登録

## 計算例

### 例1: 現在期間の利用回数

| 機能 | 利用回数 |
|------|---------|
| ログイン | 100回 |
| 見積作成 | 50回 |
| 工事登録 | 30回 |
| その他 | 0回 |
| **合計** | **180回** |

**Active率の計算：**
- ログイン: (100 / 180) × 100 = 55.6%
- 見積作成: (50 / 180) × 100 = 27.8%
- 工事登録: (30 / 180) × 100 = 16.6%
- その他: (0 / 180) × 100 = 0.0%
- **合計: 100.0%**

### 例2: すべての機能が0回の場合

すべての機能の利用回数が0の場合、Active率は0%になります。

## 実装の詳細

### 1. 利用回数の取得

現在期間の利用ログから、各機能の利用回数を取得します。

**カラム名のマッピング：**
- ログイン → `ログイン回数`
- 見積作成 → `見積作成数`
- 工事登録 → `工事登録数`
- 顧客登録 → `顧客登録数`
- 業者登録 → `業者登録数`
- 請求書作成 → `請求書作成数`
- 商品発注書作成 → `商品発注書作成数`
- 外注発注書作成 → `外注発注書作成数`
- 現場連絡表作成 → `現場連絡表作成数`
- 実行予算作成 → `実行予算作成数`
- 書類メール送信 → `書類メール送信数`
- 資料登録 → `資料登録数`
- 写真登録 → `写真登録数`
- 工程表作成 → `工程表作成数`
- タスク登録 → `タスク登録数`
- 日報登録 → `日報登録数`

### 2. 正規化処理

1. 全機能の利用回数の合計を計算
2. 各機能の利用回数を合計で割り、100を掛けてパーセンテージに変換
3. 小数点第1位まで計算
4. 丸め誤差を補正（合計が100%になるように調整）

### 3. スコア計算での使用

計算されたActive率は、スコア計算で使用されます：

- Active率 < 10% → -15点
- Active率 > 50% → +10点
- それ以外 → 0点

**注意：** スコア計算では、合計Active率（100%）ではなく、各機能の利用状況に基づいた単一のActive率値を使用します。
