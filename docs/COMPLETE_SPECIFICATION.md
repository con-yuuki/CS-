# CS Health Score システム 完全仕様書

## 1. システム概要

### 1.1 目的
企業のCS（Customer Success）状況を定量的に評価し、健康スコアを算出するシステム。

### 1.2 主要機能
1. 利用ログデータのインポート
2. Active率の自動計算
3. 健康スコアの動的計算
4. ダッシュボードでの可視化
5. 企業別の詳細情報表示

## 2. Active率計算機能

| 3 | 工事登録 | 工事登録数 |
| 4 | 顧客登録 | 顧客登録数 |
| 5 | 業者登録 | 業者登録数 |
| 6 | 請求書作成 | 請求書作成数 |
| 7 | 商品発注書作成 | 商品発注書作成数 |
| 8 | 外注発注書作成 | 外注発注書作成数 |
| 9 | 現場連絡表作成 | 現場連絡表作成数 |
| 10 | 実行予算作成 | 実行予算作成数 |
| 11 | 書類メール送信 | 書類メール送信数 |
| 12 | 資料登録 | 資料登録数 |

| 15 | タスク登録 | タスク登録数 |
| 16 | 日報登録 | 日報登録数 |

### 2.2 使用する期間

**現在期間の利用回数を使用**

- 週次データ: 対象週の利用回数
- 月次データ: 対象月の利用回数

### 2.3 学習期間方式

#### 2.3.1 利用開始日の設定
- 各企業の最初の利用ログの日付を「利用開始日」として自動設定
- データベース: `ユーザー基礎情報.usage_start_date`

#### 2.3.2 学習期間
- **期間**: 利用開始日から3ヶ月間
- **目的**: この期間の利用ログを分析して「利用する機能」を抽出

#### 2.3.3 利用する機能の抽出
- 学習期間中の利用ログを分析
- 各機能について、1回以上使用された機能を「利用する機能」として記録
- データベース: `ユーザー基礎情報.used_features` (JSONB型)

### 2.4 Active率の計算ロジック

#### 2.4.1 学習期間中

**計算方法：**
1. 全16個の機能を基準に計算
2. 現在期間の各機能の利用回数を取得
3. 全機能の利用回数の合計を計算
4. 各機能の利用回数を正規化（合計が100%になるように）

**計算式：**
```
各機能のActive率 = (機能の利用回数 / 全機能の利用回数の合計) × 100
合計Active率 = 各機能のActive率の合計 = 100%
```

#### 2.4.2 学習期間終了後

**計算方法：**
1. 「利用する機能」リストを取得（学習期間中に抽出された機能）
2. 「利用する機能」リストに含まれる機能のみを対象に計算
3. 現在期間の各機能の利用回数を取得
4. 「利用する機能」の利用回数の合計を計算
5. 各機能の利用回数を正規化（合計が100%になるように）

**計算式：**
```
各機能のActive率 = (機能の利用回数 / 利用する機能の利用回数の合計) × 100
合計Active率 = 各機能のActive率の合計 = 100%
```

#### 2.4.3 丸め誤差の補正

計算結果の合計が100%にならない場合（丸め誤差）、以下の方法で補正：

1. 合計と100%の差分を計算
2. 最大の値を持つ機能に差分を追加
3. 合計が100%になるように調整

### 2.5 スコア計算での使用

**スコア計算ロジック：**
- Active率 < 10% → **-15点**
- Active率 > 50% → **+10点**
- それ以外（10%以上50%以下） → **0点**

**注意：**
- スコア計算では、合計Active率（100%）ではなく、「利用する機能」のうち実際に使用した機能の割合を使用
- 使用した機能の割合 = (使用した機能数 / 利用する機能数) × 100

## 3. 健康スコア計算ロジック

### 3.1 基本方針

- **満点**: 100点
- **計算方式**: 減点方式（100点から減点していく）
- **インパクト企業**: 月額契約額（MRC）≥ 55,000円の企業は変動値を1.5倍に増幅

### 3.2 ステップ1: 基本変動値の計算

| カテゴリ | 項目 | 条件 | 変動値 |
|---------|------|------|--------|
| 基本利用 | ログインなし | 当該期間の利用が 0 | **-40** |
| 見積未利用 | 見積未利用 | 当該期間の作成数が 0 | **-15** |
| 工事未利用 | 工事未利用 | 当該期間の登録数が 0 | **-15** |
| Active率 | 低Active | Active率 < 10% | **-15** |
| Active率 | 高Active | Active率 > 50% | **+10** |
| トレンド | 大幅減少 | 前月/前週比で 20%以上減少 | **-10** |
| トレンド | 増加・開始 | 未利用からの開始、または 10%以上増加 | **+10** |

**変動値の合計：**
```
変動値合計 = basicUsage + estimateUsage + constructionUsage + activeRate + trend
```

### 3.3 ステップ2: インパクト係数の適用

**対象：** 月額契約額（MRC）≥ 55,000円の企業

**補正：** ステップ1で算出した「変動値の合計」を **1.5倍** に増幅

**計算式：**
```
調整後変動値 = 変動値合計 × インパクト係数
インパクト係数 = MRC ≥ 55,000円 ? 1.5 : 1.0
```

### 3.4 ステップ3: 最終スコアの計算

**計算式：**
```
最終スコア = max(0, min(100, 100 + 調整後変動値))
```

**ステータスの判定：**
- **Excellent**: スコア ≥ 90
- **Stable**: スコア ≥ 70
- **Warning**: スコア ≥ 50
- **Critical**: スコア < 50

### 3.5 計算例

#### 例1: 通常企業（MRC < 55,000円）

**前提条件：**
- ログイン回数: 36回
- 見積作成数: 12回
- 工事登録数: 11回
- Active率: 30%（使用した機能の割合）
- 前期間比: ログイン回数が10%増加

**変動値の計算：**
- 基本利用: 0（ログインあり）
- 見積未利用: 0（見積作成あり）
- 工事未利用: 0（工事登録あり）
- Active率: 0（10%以上50%以下）
- トレンド: +10（10%以上増加）
- **変動値合計: +10**

**インパクト係数：**
- MRC < 55,000円 → 係数: 1.0

**最終スコア：**
- 最終スコア = max(0, min(100, 100 + (10 × 1.0))) = 110 → **100**（上限）
- ステータス: **Excellent**

#### 例2: インパクト企業（MRC ≥ 55,000円）

**前提条件：**
- ログイン回数: 0回
- 見積作成数: 0回
- 工事登録数: 0回
- Active率: 5%（使用した機能の割合）
- 前期間比: ログイン回数が30%減少
- MRC: 60,000円

**変動値の計算：**
- 基本利用: -40（ログインなし）
- 見積未利用: -15（見積作成なし）
- 工事未利用: -15（工事登録なし）
- Active率: -15（Active率 < 10%）
- トレンド: -10（20%以上減少）
- **変動値合計: -95**

**インパクト係数：**
- MRC ≥ 55,000円 → 係数: 1.5

**最終スコア：**
- 調整後変動値 = -95 × 1.5 = -142.5
- 最終スコア = max(0, min(100, 100 + (-142.5))) = **0**（下限）
- ステータス: **Critical**

## 5. 処理フロー

### 5.1 インポート処理

1. **ファイルの読み込み**
   - Excel/CSVファイルをアップロード
   - ファイルをパースしてデータを抽出

2. **データの検証**
   - テナントIDの存在確認
   - 必須項目の確認

3. **利用ログの保存**
   - 各機能の利用回数を取得（16個の機能）
   - 利用ログを`usage_logs`テーブルに保存

4. **利用開始日の設定**
   - 初回インポート時、利用開始日が設定されていない場合
   - 現在の期間日を利用開始日として設定

5. **Active率の計算**
   - 現在期間の利用ログから各機能の利用回数を取得
   - 学習期間中かどうかを判定
   - Active率を計算
   - 計算結果を`usage_logs`テーブルの`Active率`カラムに保存

6. **利用する機能の更新**
   - 学習期間終了後、自動的に「利用する機能」を抽出
   - `used_features`カラムに保存

### 5.2 スコア計算処理（動的計算）

1. **データの取得**
   - すべての企業を取得
   - すべての利用ログを取得

2. **最新期間の特定**
   - すべての利用ログから最新の期間日を特定

3. **企業ごとのスコア計算**
   - 最新期間の利用ログを取得
   - 前期間の利用ログを取得（比較用）
   - Active率を計算（未計算の場合は自動計算）
   - スコアを計算

4. **結果の返却**
   - スコア順にソートして返却

### 5.3 ダッシュボード表示

1. **スコアデータの取得**
   - 動的にスコアを計算
   - 企業情報と結合

2. **フィルタリング**
   - 検索クエリでフィルタ
   - ステータスでフィルタ
   - インパクト企業でフィルタ

3. **統計情報の計算**
   - 平均スコア
   - ステータス別の件数
   - インパクト企業の件数

### 5.4 詳細モーダル表示

1. **企業カードのクリック**
   - 選択された企業の情報を取得

2. **詳細情報の取得**
   - 現在期間の利用ログを取得
   - 前期間の利用ログを取得
   - スコア計算の詳細を取得

3. **表示**
   - スコア概要
   - 利用状況（16個の機能の利用回数）
   - スコア詳細（各項目の変動値）
   - 計算式

## 7. エッジケース

### 7.1 利用回数がすべて0の場合

**Active率の計算：**
- すべての機能のActive率を0%とする
- 合計: 0%（100%にはならない）

**スコア計算：**
- 使用した機能の割合: 0%
- スコア変動値: -15点（Active率 < 10%）

### 7.2 利用する機能が1つのみの場合

**Active率の計算：**
- その機能のActive率を100%とする
- 合計: 100%

**スコア計算：**
- 使用した機能の割合: 100%（その機能を使用した場合）
- スコア変動値: +10点（Active率 > 50%）

### 7.3 学習期間中に利用ログがない場合

**処理：**
- 利用開始日は設定されるが、「利用する機能」は空のリストになる
- 学習期間終了後も、全機能を基準に計算を続行

### 7.4 利用開始日が設定されていない場合

**処理：**
- 最初の利用ログの日付を利用開始日として自動設定
- その後、通常の処理フローに従う
